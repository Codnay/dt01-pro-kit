Obstacle protection during manual driving

Checking sensor readiness…

Engage the physical emergency stop or software brake first. This enables and verifies the available controller safety switches; it never releases the brake. Missing, disabled or stale obstacle readings show a warning and allow manual driving without verified obstacle protection. Detected obstacles and cliff hazards still block movement, including turns.

Laser-based manual stopping and clearance around the arms have not been verified. Sensor configuration is not a physical stopping test.
